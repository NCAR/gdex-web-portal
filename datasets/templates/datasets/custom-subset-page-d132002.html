Please enter one or more station identifiers to extract from the ISPD dataset, given as a comma-separated list. Station identifiers should be entered as the 5- or 6-digit WMO international synoptic identifier. For example, enter "72565, 72469, 72530" to request Denver International Airport, Denver Stapleton Airport, and Chicago O'Hare Airport. A blank entry will retain all stations in the ISPD database. Click here to search for station information in the WMO Oscar/Surface repository, or you may look up station IDs in the ISPD version 4 inventory here.
Please enter one or more location or station names to extract from the ISPD dataset, given as a comma-separated list. For example, "Denver, Chicago, New York". This service searches for matches in the 30-character ship or station name field stored in the ISPD Tracking Table described on page 21 of the ISPD version 4 documentation (see here for a description). For a complete listing of station names in the ISPD version 4, please consult the inventory of ISPD stations here. Note that partial location names may be entered and will return all observations matching the given station name. For example, "London" will return observations for London Heathrow Airport, London Gatwick Airport, and other observation records with "London" in the station name field.
